Performance parameters

Thermal Engineering-II · DI05019021 · IP · BP · SFC · Efficiency

What you should be able to do

  • Define IP, BP and FP and write IP = BP + FP.
  • Write torque from brake power and speed.
  • Calculate SFC and mechanical / brake thermal efficiency.
  • Know Morse test (multi-cylinder SI) in one sentence.

2-minute idea

Indicated power (IP) is the power at the piston from the gas forces — what the indicator diagram would give.

Brake power (BP) is the power at the crankshaft / brake drum — what you can sell.

Friction power (FP) is the difference: bearings, piston drag, pumps, fan. Always IP = BP + FP.

Formula sheet

QuantityFormula (SI units)
IPIP = BP + FP
Mechanical ηη_m = BP / IP
Brake powerBP = 2πNT / 60 (N in rps? No: N rpm → BP = 2πN T / 60000 kW if T in N·m)
SFCbsfc = ṁ_f / BP (kg/kW·h if ṁ_f in kg/h)
Brake thermal ηη_bth = BP / (ṁ_f × CV) (same units)
Indicated thermal ηη_ith = IP / (ṁ_f × CV)

Keep units consistent. If BP is in kW and CV in kJ/kg, convert hours ↔ seconds.

Exam extra words

  • Morse test — cut spark (or injection) on one cylinder of a multi-cylinder SI engine; drop in BP ≈ IP of that cylinder. Sum to get total IP. Not for single-cylinder.
  • Willan’s line — diesel: plot fuel vs BP and extend to zero fuel; intercept ≈ FP.
  • Volumetric efficiency — actual mass of air taken in / mass that would fill the swept volume at inlet conditions.
  • Specific output — BP per unit piston area or per litre, used to compare engines.

5 practice questions

If you still don’t get it

  • Mistake: Writing η_m = IP / BP. Mechanical efficiency is BP divided by IP (always less than 1).
  • Mistake: Using N in rps inside 2πNT/60 when the book took N as rpm. Check the printed formula first.
  • Mistake: Morse test on a single-cylinder engine. You need several cylinders so one can be cut out.
